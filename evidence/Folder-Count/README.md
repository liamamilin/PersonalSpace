## 剩余问题和下一个能力

轻量统计仍需遍历目录，数量表示当次可读取的范围，不是瞬时文件系统快照；未读位置不计入，后续文件变化可能改变实际入库数量。当前没有预设数量硬上限，由用户按数量决定是否继续。既有来源的启动补扫、手动刷新和局部自动更新沿用原流程。本轮未运行真实百万文件目录或补测其计数耗时；取消统计的代码路径由隔离测试覆盖，没有另行留存统计中途取消的 GUI 截图。后续可根据用户确定的数量范围增加自动拒绝规则。产物为本机证书开发构建，未做 Developer ID 公证。
