# M5 · 照片与敏感资料

## 完成能力

PhotoKit 由用户主动连接后读取元数据和本机缓存预览，只读、禁网，不进入图库包，不导出照片原图。照片使用稳定 localIdentifier 保存并关联对象，失权保留不可用占位。大预览本机资源不可用时仅回退一次至本机 320 缓存，授权/取消错误继续明确失败。

正式迁移加入来源/资料类型和普通/疑似敏感/敏感分类。名称和凭据类型触发候选；刷新保留手动分类。非普通资料不做正文读取/FTS/模型，标敏感原子移除已有正文索引，改普通后需要再次明确索引。模型和 OCR 入口先读取最新数据库状态，避免旧编辑器绕过；照片不做 OCR/正文索引。

## 真实操作

- 合成密码文件首次扫描自动疑似敏感；启用正文搜索，独有正文词「紫杉密语」0 结果：通过。名称仍可检索。
- 显式标普通、点击识别并保存正文后同词 1 结果；再标敏感立即变为 0 结果：通过。
- 用户两次明确授权系统照片读取并处理系统弹窗后，真实 3 张照片的元数据/缩略图显示：通过。只在本机操作，未上传照片或实际截图。
- 选 1 张真实照片关联「我的电脑」；最终 Release 空格预览、缩放到 130%、适应窗口：通过。
- 同一 Release 退出重启，13 份资料及对象中的 3 条关联保留，照片预览继续可用，无需再次授权：通过。
- 开发构建代码变化导致 macOS 再次要求授权时，旧照片关联显示不可用，占位仍在，普通文件继续工作：通过。拒绝/撤权的数据恢复分支另有单测；未手动撤销用户现有系统权限。

## 限制

每次最多取最近 500 张照片元数据；iCloud 仅云端资源不会下载。大图清晰度受本机缓存限制。「打开照片 App」只打开系统应用本身，不保证定位具体照片。无稳定 Developer ID 的 ad hoc 代码更新可能触发重新授权。本阶段提供标记与处理边界，不提供密码保险箱；已保存的用户校对事实不自动删除。
