# 大目录扫描与查询性能修复 · 0.10.6 (21)

## 完成能力

定位并修复三处实际开销：扫描循环积累 Foundation 临时对象；每次界面刷新用全部 item 记录计算待整理；少量命中的名称查询按名称索引随机读取整个表。扫描逐条使用 autoreleasepool，数据库增加仅包含 `kind='imported'` 的候选索引；稀疏全局名称搜索顺序过滤再排序。限定来源、对象、事务、托管、待整理和多页查询保留原计划。空结果和只取数量时跳过重复提取资料。

真实界面复现扫描每秒刷新列表，导致约一秒以上的搜索不断被新查询作废。现有查询进行时，扫描跳过列表查询，只更新进度；其他导航、编辑和扫描结束的必要刷新保留。`⌘F` 现在打开主资料库窗口并请求搜索焦点。未改变符号链接校验、目录排除、原件只读、权限边界、历史资料关联、显式正文索引等规则。没有增加扫描守护进程或复制第三方实现。

## 剩余问题和下一个能力

固定签名构建 21 的完整遍历、搜索、内存及局部更新均已验证。全目录启动补扫仍慢，采样显示逐文件元数据处理和索引写入仍有开销；下一个紧邻改进是减少未变化文件的索引写入。实际百万级名称搜索仍约一秒，没有声称即时搜索。当前 144 个位置未能读取，按报告保留，未自动扩大系统权限。首次由临时签名切换证书可能再次询问文件夹权限；其他应用容器的数据访问许可还可能只对本次运行有效，参见 [Apple TN3127](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements) 和 [WWDC23 隐私说明](https://developer.apple.com/videos/play/wwdc2023/10053/)。此为本机证书构建，未做 Developer ID 公证。
