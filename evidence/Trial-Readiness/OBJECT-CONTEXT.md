# 凭证创建事务的对象上下文 · 2026-10-30

**完成能力**：创建事务会固定本次操作的凭证 ID 和当前对象上下文。具体对象页面优先使用当前对象；其它文件页面查询凭证的真实对象关联，唯一关联自动预选，多关联保持未选并在现有编辑器提示选择，无关联保持原行为。用户仍可更改或清除对象，保存不会修改凭证已有的对象关系。没有数据库迁移或新关系服务。

**用户操作路径**：在当前开发账户的独立空合成资料库中，由 ZIP 解压后的 Release App 收纳订单 PDF，将订单和来源发票关联「我的电脑」。回到「所有资料」从 PDF 创建保修，实际编辑器预选「我的电脑」；保存事实和两条行动后，对象详情直接显示保修事务与下一步行动。未关联时显示「不关联对象」；同一 PDF 再关联「家庭设备」后，从「已托管」创建订单，未自动选择对象并显示明确提示，手动选择「我的电脑」后正常保存。从「家庭设备」资料页新建事务则预选当前对象。原 PDF 的两个对象关联均保留。

**构建/测试证据**：完整 84 项测试、0 失败，40.378 秒，包含两项针对性回归：异步查询期间切换选择仍使用原凭证、唯一对象预选及保存后可查、清除事务对象不解除凭证关联、无/多关联与明确对象上下文。Debug / Release 构建成功。原始日志、xcresult 保留本机 `.build/Trial-Readiness/`；截图保留本机 `evidence/Trial-Readiness/gui/`：`03-no-object-preselection.png`、`04-single-object-preselected.png`、`08-object-related-matter.png`、`09-multiple-object-choice.png`、`11-explicit-object-context.png`。不公开真实环境截图或系统路径。
