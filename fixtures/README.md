# 真实能力的合成测试素材

这里不存放用户真实资料、账号、密码、身份证或私人照片。`sample_cases.json` 是给 Codex 生成**专用临时测试目录**的参考测试场景，不是待完成的 100 项门禁。

优先验证当前阶段的一条完整演示路径：M1 的授权→扫描→查找→打开；M2 的关联→托管；M3 的订单→日期→提醒。OCR 图片/PDF 需要在本机生成或使用明确授权的样本；仅 JSON 结构不能证明 OCR 真实有效。

`M7/` 包含三份可直接在 Finder 拖放的合成文件：`M7-收纳订单.pdf`、`M7-设备照片.png`、`M7-整理说明.txt`。PDF/PNG 复用 M1 合成素材，TXT 明确标记测试用途；均不含私人资料。应用不会自动导入。
